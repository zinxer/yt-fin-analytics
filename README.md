# YouTube Sentiment Analysis for Financial Markets

A data analysis project that correlates YouTube video transcripts with financial market movements using Natural Language Processing (NLP) and Large Language Models (LLMs).

## Overview

This project aims to uncover relationships between public sentiment expressed in YouTube content and price movements in stocks and cryptocurrencies. By analyzing video transcripts using advanced LLMs and sentiment analysis, we can potentially identify patterns that influence market behaviour.

## Features

- Automated YouTube video transcript extraction
- Sentiment analysis using LLMs
- Historical and real-time price data integration for:
  - Stocks
  - Cryptocurrencies
- Correlation analysis between sentiment and price movements
- Interactive visualisations and reports

## Technical Stack

- **Data Processing**: Python, Pandas
- **Machine Learning**: Large Language Models for transcript analysis
- **APIs**:
  - YouTube Data API for video data
  - Financial market APIs for price data
- **Data Storage**: MySQL with proper indexing
- **Analysis Tools**: Jupyter Notebooks
